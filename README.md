
# Privacy Policy for Kubo Discord Bot

**Last updated:** January 2026

Kubo is a Discord bot designed to provide server moderation, automation,
and management features.

## 1. Data Collection
Kubo processes Discord user data only as required to perform its features.
This may include:
- User IDs
- Server IDs
- Message content (only for real-time moderation purposes)

## 2. Message Content
Message content is analyzed in real time to detect rule violations,
blocked words, and spam patterns.

Kubo does **NOT** permanently store message content.
All processed message content is discarded immediately after evaluation.

## 3. Data Storage
Kubo does not store any sensitive personal data off-platform.
Only minimal server configuration data is stored, such as:
- Role IDs
- Channel IDs
- Server-specific settings

## 4. Data Sharing
Kubo does not share, sell, or distribute user data to any third parties.

## 5. Machine Learning / AI
Collected data is **NOT** used to train machine learning or AI models.

## 6. User Control
Server administrators can enable or disable Kubo’s features at any time.

## 7. Contact
If you have questions about this Privacy Policy,
please contact the bot developer via Discord.
